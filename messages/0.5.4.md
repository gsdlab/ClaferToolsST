Clafer Tools 0.5.4 for Sublime Text 4
=====================================

Clafer Tools now requires Sublime Text 4 and Clafer 0.5.3 or later.

* The compiler's errors are shown in the model, at their position. An error in
  a file that the model imports (`--import`, Clafer 0.5.4) is shown at the
  start of the model, with the file and the position in it, and in that file
  if it is open; double-click the error in the output panel to open the file
  at the error.
* The instance generators run in a Terminus tab instead of SublimeREPL:
  install the package `Terminus` with Package Control. The SublimeREPL
  configuration that you copied into `Packages/SublimeREPL` is no longer used.
* The tools are found on `PATH`, or in the folder set by `tools_path` in
  `Preferences > Package Settings > Clafer Tools > Settings`, instead of
  `Packages/Clafer-Bin`.
* `ctrl+i, g, a` and `ctrl+i, g, c` work only in Clafer models, so `ctrl+i`
  (incremental find) works again in other files
  ([#4](https://github.com/gsdlab/ClaferToolsST/issues/4)).
* The syntax highlighting follows the Clafer grammar: compiler directives
  (`//# OPTIONS` on the first line, `//# FRAGMENT`, …), embedded Alloy and
  JavaScript blocks, escapes in strings, and names with apostrophes.
* The Z3-based instance generator (`ctrl+i, g, s`) is gone; ClaferSMT is no
  longer part of the Clafer tools.
